# MyVector

A simple custom implementation of a dynamic array similar to `std::vector`
written in C++ using templates.

This project was created for learning:
- Dynamic memory allocation
- Templates in C++
- Operator overloading
- Resizable containers
- Manual memory management

---

## Features

✅ Generic template support  
✅ Dynamic resizing  
✅ `push_back()` support  
✅ `operator[]` indexing  
✅ Automatic capacity growth  
✅ Size and capacity tracking
